# へっくめっく

スマホ・PCのブラウザで遊べる、あなた1人とCPU2〜3人のサイコロゲーム。外部サービスやAPIキーは不要です。

## 起動

Node.js 22以上で、リポジトリ内から実行します。追加の依存パッケージはありません。

```sh
npm start
```

ポートは5173（`PORT`で変更可）。スマホからは同一ネットワーク上のホストのアドレスを使用してください。

```sh
npm test
```

目をタップして同じ目をすべて確保し、振り直すかタイルを獲得するか選択します。画面の「遊び方」でルールを確認できます。途中状態はブラウザのlocalStorageに自動保存されます。CPUの処理後は自動で進行し、人間の手番終了後は「次の手番へ」で進みます。

虫の数は21〜24が1匹、25〜28が2匹、29〜32が3匹、33〜36が4匹。同点は同順位。失敗時は手持ちタイルを返却した場合のみ、返却前に中央にあった最大タイルを裏返します。手持ちタイルがなく返却できない場合は、中央のタイルを裏返しません。

## PWA / 公開

GitHub Actions の `Publish PWA to GitHub Pages` が main へのpush時にテストし、静的ファイルのみを公開します。GitHubの Settings → Pages → Source は GitHub Actions を選択してください（権限があればワークフローが自動有効化を試みます）。

HTTPSで最初に開いた後、オフラインでも遊べます。Androidでは「アプリを追加」またはブラウザのインストール、iPhoneではSafariの共有 →「ホーム画面に追加」を利用してください。ゲームの保存は端末・ブラウザごとで、オンライン対戦や端末間同期はありません。
